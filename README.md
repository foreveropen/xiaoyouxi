# 合成大西瓜 · 2D 物理小游戏

一个基于 [Matter.js](https://brm.io/matter-js/) 的轻量 2D 物理合成游戏。移动鼠标瞄准，点击掉落水果，相同水果碰撞后合成更大的，一路合到西瓜；堆过红线即失败。

## 在线试玩

直接打开 `index.html` 即可游玩（无需构建、无后端依赖）。

## 玩法

- 鼠标 / 手指移动瞄准，点击掉落水果
- 两个相同水果发生物理碰撞后自动合成下一级
- 1.2 秒内连续合成触发连击倍率，分数翻倍
- 水果堆过顶部红色虚线线即游戏结束
- 最高分数通过 localStorage 持久化

## 水果进化链

🍒 樱桃 → 🍓 草莓 → 🍇 葡萄 → 🥝 猕猴桃 → 🍊 橙子 → 🍎 苹果 → 🍐 梨 → 🍑 桃 → 🍍 菠萝 → 🍉 西瓜

## 技术要点

- **物理引擎**：Matter.js（重力、圆-圆碰撞、冲量、restitution 弹跳）
- **渲染**：原生 Canvas 2D，DPR 适配
- **音效**：WebAudio 实时合成，无外部资源
- **零依赖构建**：单 HTML 文件，CDN 引入 Matter.js
- **响应式**：桌面鼠标 + 移动触屏 pointer 事件统一处理
